# Changelog

## 1.0.0 - 2026-10-19

- Initial release of the `archer-irm-api` plugin, built from the Archer API Help 2026.08.
- OpenAPI 3.1 spec covering the RESTful Platform API, V2 API, Data Gateway API, Content API and the NGRX entry point (115 operations).
- Skill references: REST quick reference, field-type encodings, Content API, SOAP transport and `SearchReport` grammar, generated catalog of 108 SOAP methods, Data Gateway, gotchas, and a Markdown snapshot of all 245 help pages with 84 example payloads.
- Dependency-free Python clients: `archer_rest.py` (REST/V2/Content API) and `archer_soap.py` (SOAP).
