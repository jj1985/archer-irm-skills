---|---|---|---

  * Access Role Created
  * Access Role Deleted
  * Access Role Modified
  * Account Status Changed
  * Configuration Admin Added
  * Configuration Admin Deleted
  * Content Admin Added
  * Content Admin Deleted
  * Content Decrypted In Bulk
  * Content Encrypted In Bulk
  * Login Failed

| 

  * Full Module Content Delete
  * Report Permission Granted
  * Report Permission Revoked
  * LDAP Configuration Delete Started
  * LDAP Configuration Delete Completed
  * Login Retries Exceeded
  * Password Changed by Admin
  * Password Changed by User

| 

  * Pin Request Successful
  * Pin Request Failed
  * Password Reset Requested
  * Role Assigned to User
  * Role Removed from User
  * Security Events Started
  * Security Events Stopped
  * Security Parameter Assignment Changed
  * Security Parameter Created
  * Security Parameter Deleted
  * Security Parameter Modified
  * SubForm Config Admin Added
  * SubForm Config Admin Deleted
  * Translation Export Requested

| 

  * Translation Import Requested
  * User Added
  * User Deleted
  * User Account Modified

  * Full Name Modified
