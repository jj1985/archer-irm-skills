# Determine Application GUIDs (WS)  
  
Some methods require an application Globally Unique Identifier (GUID) as a parameter. Use the following procedure to find an application GUID.

## Procedure  

  1. From the menu, click  > Application Builder > Applications.
  2. In the Applications section, click the name of the application for which you want the GUID. 
  3. In the General Information section, the ID field contains the application GUID.
